# Animals and Nature Messages

REST API for Animals and Messages administrator dashboard where administrators could view user feedback.  This is a Spring Boot REST API that provides CRUD operations for emails pertaining to the Animals and Nature message board.  AWS SNS and AWS Lambda were used to receive email messages and send the messages to the API.  Authorization was built in using OAuth 2.0.  This API was originally hosted on Google Cloud Platform and it now currently hosted on Render.  You would need an administrator account to access the API.  Accounts are created by administrators, not end users.  You could view the GitHub repository for the Animals and Nature message board via this [link](https://github.com/starrv/animals-and-nature) where you could view a full demonstration.  NOTE:  I am currently using the free plan so startup could take several minutes.
